**Festival Lampion** — a spot-the-difference game with five original hand-drawn
scenes (Lantern Night Market, Coral Reef, Enchanted Garden, Space Station,
Twilight Bookshop), seven differences in each. All art is inline SVG drawn by
the game's own code — no image files, no network requests, fully offline.

Find differences by clicking either panel, beat the 90-second timer, use
hints (H), and chase the best score (saved in localStorage). Stars are
awarded per level for speed, and levels unlock as you complete them.

## Run it

```
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

To build the hand-in:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
